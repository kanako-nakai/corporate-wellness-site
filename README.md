# Kanako Nakai Portfolio

Next.js portfolio site featuring the Corporate Wellness landing page.

## Local development

```bash
pnpm install
pnpm dev
```

Open `http://localhost:3000/corporate-wellness`.

## Production check

```bash
pnpm build
pnpm start
```

## Deployment

The project is designed to deploy on Vercel through the connected GitHub
repository. Pushing changes to the `main` branch triggers a production
deployment.
